NUESTRA AVENTURA — app privada familiar
1. Estos archivos forman una PWA: una app web instalable en iPhone.
2. Para usarla como app en varios iPhone, hay que subir esta carpeta a un alojamiento web con HTTPS.
3. En el iPhone: abrir el enlace en Safari > Compartir > Añadir a pantalla de inicio.
4. La versión actual guarda los cambios en el dispositivo mediante almacenamiento local. Para que todos vean exactamente los mismos cambios, habrá que añadir una base de datos/sincronización en una segunda versión.
